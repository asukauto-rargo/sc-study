# 情報処理安全確保支援士 学習アプリ

忘却曲線（間隔反復）で知識を定着させ、過去問の演習記録を蓄積するための個人用Webアプリ。
スマホでもPCでも同じURLで開けて、データはすべてクラウドに残る。

公開URL: https://asukauto-rargo.github.io/sc-study/

- **フロント**: Vite + React + TypeScript（素のCSS、依存は最小）
- **データ**: Supabase（Postgres + 認証）
- **公開**: GitHub Pages（`main` に push すると GitHub Actions が自動デプロイ）

## 方針：教材の複製は持たない

講座教材（購入コンテンツ）は、PDFもテキストも**このアプリとデータベースには一切置かない**。
Udemy の利用規約が受講生に与えるのは「サービス経由で閲覧するライセンス」のみで、
複製・送信・譲渡は書面による許可なしには認められていないため。

このアプリに入るのは次の2つだけ。

1. **自分の言葉で書いた復習カード** — 教材の転載ではなく、要点を設問の形に組み立て直したもの
2. **IPA が公表している過去問** — IPA は再利用を許諾している（出典明記が条件）

資料そのものは手元の `学習資料/` フォルダで読む。`.gitignore` 済みなのでリポジトリにも入らない。

## できること

| 画面 | 内容 |
|---|---|
| ホーム | 今日やるべき復習枚数、連続日数、30日定着率、今後14日の復習予定、分野別の進捗 |
| 復習 | カードをめくって4段階で自己採点。`Space` でめくり、`1`〜`4` で採点 |
| カード | カードの追加・編集・保留・初期化。分野で絞り込み |
| 問題 | 科目A-1 / A-2 の四肢択一ドリル。誤答は自動で復習キューに入る。解説は過去問道場へリンク |
| 問題 → 科目B | 本番と同じ「画面で長文を読んでキーボードで解答」の練習。タイマーと自己採点つき |

## 1. セットアップ

### アプリを使い始める

公開URLを開いて「はじめて使う（アカウント作成）」からメールアドレスとパスワードを登録する。
Supabase の Authentication → Sign In / Providers → Email → Confirm email はオフにしてあるので、
登録した瞬間に使える。

### ローカル開発

```bash
cd app
npm install
npm run dev -- --host     # http://localhost:5173
```

接続先は `app/src/lib/supabase.ts` に既定値が入っている（publishable key は公開前提の鍵で、
データの保護は RLS が担っているのでリポジトリに入っていて問題ない）。
別の Supabase プロジェクトに向けたいときだけ `app/.env.local` を作って上書きする。

### デプロイ

`main` に push するだけ。GitHub Actions が `app/` をビルドして Pages に公開する。
Pages の Source は **GitHub Actions** に設定済み。

---

## 2. カードを入れる

`seeds/*.json` に書いたカードを取り込む。`*.local.json` は `.gitignore` 済みなので、
手元だけに置きたいカードはそちらに書く。

```bash
cd tools
cp .env.example .env        # SC_EMAIL / SC_PASSWORD を自分のものにする
npm install
npm run ingest:cards
```

JSONの形式:

```json
[
  { "deck": "暗号技術", "front": "…", "back": "…", "note": "…", "tags": ["…"], "key": "crypto-001" }
]
```

`key` は再実行時の重複防止に使う。省略すると `deck` と `front` から自動生成される。

カードはアプリの「カード」画面からも直接追加・編集できる。

## 3. 過去問の演習

### 科目A（午前Ⅰ / 午前Ⅱ）

**IPA の問題PDFはコピー禁止の保護がかかっており、テキストを取り出せない。**
（`Encrypted: yes (copy:no)` / 抽出文字数 0）。保護の解除はしない方針なので、
問題文をアプリに取り込むことは諦め、**演習は過去問道場で行い、アプリは記録と復習を担う**
設計にしている。

アプリの「問題」タブでの流れ:

1. 年度と区分を選ぶと 問1〜問25（午前Ⅰは30）の番号グリッドが出る
2. 番号を押すと、その問題の過去問道場ページが新しいタブで開く
3. 解いて解説まで読んだら、アプリに戻って ○ か × を押す
4. × を押すと、その場で復習カードを書く欄が開く（問題文の写しではなく、
   分かっていなかったことを自分の言葉で問いにする）
5. ○ を押すと次の未解答へ自動で進む

記録は `question_attempts` に残り、ダッシュボードに正答率が出る。
「誤答一覧」モードで、間違えた問題だけをいつでも開き直せる。

`questions` テーブルには問題文を持たず、出典と過去問道場へのリンクだけを記録している。

### 科目B（午後 / 記述）

IPA の問題PDFを画面の横に開いて読み、アプリのテキストエリアに解答を打つ。
これは本番のCBTに一番近い練習でもある。
解答例と採点講評を見て自己採点した点数と所要時間が記録として残る。

問題PDFは手元に置いておくと速い。

```bash
cd tools
npm run download -- --years 6 --only pm   # 直近6回の午後問題と解答例
```

`過去問/<試験回>/` に保存される（`.gitignore` 済み）。
アプリの画面からは IPA のサイト上のPDFへ直接リンクしているので、
ダウンロードしなくても使える。

### 著作権について

IPA は公表済みの過去問題の利用を許諾しているが、著作権は放棄しておらず出典の明記が必要。
このアプリは問題文を複製していないが、記録した問題には
`出典：令和7年度 秋期 情報処理安全確保支援士試験 午前Ⅱ 問1` の形式で出典を保存している。

過去問道場（sc-siken.com）の解説は同サイトの著作物なので、**リンクを張るだけ**で
コピーはしていない。解説は本家で読む。

## 4. 忘却曲線のアルゴリズム

SM-2 をベースにした間隔反復。採点は4段階。

| 操作 | 易しさ係数 | 次の間隔 |
|---|---|---|
| もう一度 | −0.20 | 10分後 |
| 難しい | −0.15 | 復習段階なら 間隔×1.2、学習中なら12時間後 |
| できた | 変化なし | 初回は1日、以降は 間隔×易しさ係数 |
| 簡単 | +0.15 | 初回は4日、以降は 間隔×易しさ係数×1.3 |

- 易しさ係数は 1.3〜3.0 に収まる（初期値 2.5）
- 間隔の上限は 365日
- 2日以上の間隔には ±5% のゆらぎを入れて、同じ日に大量に溜まるのを防いでいる
- 判定と履歴の記録は Postgres の `grade_card()` 関数で一度に行うので、
  途中で通信が切れても状態がずれない

実装: `supabase/migrations/0002_functions_and_seed.sql`

## 6. ディレクトリ構成

```
.
├── app/                    # Webアプリ（GitHub Pages に公開される）
│   ├── src/pages/          # 画面
│   └── src/lib/            # Supabaseクライアント、型、整形
├── tools/                  # Macのターミナルで実行するスクリプト
│   ├── download-past-exams.mjs
│   ├── ingest-past-exams.mjs
│   ├── ingest-cards.mjs
│   └── purge-storage.mjs   # 誤ってアップロードしたものを消す保険
├── supabase/migrations/    # スキーマ
├── seeds/                  # カードのシード（*.local.json は git管理外）
├── 学習資料/                # 講座PDF（git管理外。アプリには取り込まない）
└── 過去問/                  # IPA公表PDF（git管理外）
```

## 7. よくある操作

```bash
# カードを足したあと
cd tools && npm run ingest:cards

# 過去問を足したあと
cd tools && npm run download -- --sitting 07_aki && npm run ingest:past-exams

# アプリを直したあと（これだけで公開URLが更新される）
git add -A && git commit -m "..." && git push
```
